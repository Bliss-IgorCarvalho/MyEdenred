### **\[BO-Conteúdos\] Gestão de Conteúdos dos Produtos (FAQs e Condições)**

1. **Funcionalidade**  
   1. O colaborador deve poder gerir os conteúdos específicos de cada produto Edenred (FAQs e Condições) — Cartão Refeição, Cartão Flexível, Wallet Creche, Wallet Educação.

2. **Requisitos Funcionais (As-Is)**  
   1. Existe seleção do produto (dropdown).  
   2. Para cada produto pode-se:  
      1. **Editar Condições Gerais** (documento legal) com data de validade — editor de texto que aceita formatação (com truques: passar para plain text antes de colar de Word).  
      2. Gerir **Perguntas Frequentes**: criar nova, suspender, eliminar, editar — cada pergunta tem **estado** (Publicado / Suspenso). Não há categorias para FAQs por produto. Pode-se **ordenar** as perguntas (mover para primeira, etc.).  
   3. **Não existem categorias** para FAQs por produto (apenas para FAQs gerais).

3. **Gaps (To-Be)**  
   1. Considerar **editor de texto rico mais completo** (atualmente limitado, com fluxo manual de plain text \+ HTML para garantir formatação) — Demo refere "quanto mais possibilidades de edição, melhor".
