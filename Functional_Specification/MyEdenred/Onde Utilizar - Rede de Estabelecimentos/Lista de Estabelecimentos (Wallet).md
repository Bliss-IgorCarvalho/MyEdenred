### **\[Onde Utilizar\] Lista de Estabelecimentos (Wallet)**

1. **Contexto**  
   1. Para **Wallets**, os dados de estabelecimentos vêm dos sistemas Edenred em **tempo real** (a parceria tem de estar ativa no momento, dado que o pagamento é digital).

2. **Funcionalidade**  
   1. O utilizador titular de uma Wallet deve poder consultar a lista de estabelecimentos aderentes (escolas/creches)

3. **Requisitos Funcionais (As-Is)**  
   1. A lista vem diretamente dos sistemas Edenred (não da MyGon).  
   2. **Não existe vista em mapa** para Wallets.  
   3. As informações apresentadas são mais limitadas comparativamente a Cartões.
