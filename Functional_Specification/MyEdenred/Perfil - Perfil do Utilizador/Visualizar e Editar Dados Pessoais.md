### **\[Perfil\] Visualizar e Editar Dados Pessoais**

1. **Funcionalidade**  
   1. O utilizador deve poder visualizar e editar os seus dados pessoais (nome, data de nascimento, código postal) no ecrã de perfil.

2. **Requisitos Funcionais (As-Is)**  
   1. O ecrã de perfil exibe: nome, data de nascimento, NIF (não editável), código postal.  
   2. O **NIF é exibido como dado fixo, não editável** (apenas se aplica quando o utilizador tem uma Wallet).  
   3. O utilizador pode alterar o nome, data de nascimento e código postal diretamente..
